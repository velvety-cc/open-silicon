# Risks

- This app owns the single-deal GPU financing, default and original-principal
  recovery model. Read `docs/FORMULAS.md` and `docs/CALCULATION_PLAN.md` before
  changing financial behavior. Keep model units, provenance and balance
  reconciliation explicit.
- Keep app, worker and model independent of the website, deck and other apps.
  Shared brand copies are generated by the root `assets:sync` allowlist.
- `data/source-snapshot.json` and `data/live-source.json` are historical source
  evidence. An audit must not silently overwrite them. The original XLSX stays
  in the external production materials workspace.
- Generated builds, reports and audit results go to the configured artifacts
  directory or ignored `.artifacts/`. Keep editable conservative example inputs
  and compact reference results in source.
- Verify changes with `npm test`, `npm run typecheck`, `npm run build:risks` and
  `npm run verify:risks`. Update reference results only for intentional model
  changes and explain the numerical difference.
