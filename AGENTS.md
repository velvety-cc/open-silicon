## Brand spelling

Always write the brand as **OpenSilicon**, with capital O and S and no space in the middle. Apply this spelling consistently to UI copy, headings, metadata, accessibility labels, documentation and future replies about this project.

## Repository boundaries

- The active applications are `apps/web`, `apps/deck`, `apps/other-materials` and `apps/risks`. Keep their layouts, styles, routing and build outputs independent.
- GPU risk analysis lives in `apps/risks`; preserve its own financial model, source evidence and tests. Original workbooks and generated reports remain external.
- Shared packages never import application or archived code. Run `npm run check:architecture` after structural edits.
- `packages/content` contains public facts only. Keep private transaction content in the deck or its owning standalone material; never in public shared content.
- Edit shared brand assets in `packages/brand`; application icon copies are generated by `npm run assets:sync`.
- The current deck is the 14-page source in `apps/deck/decks/fund-1`. The earlier 20-page React deck is historical source.
- Tear sheets and other standalone material source live in `apps/other-materials`; read its README before editing. Generated releases stay external or ignored.
- Read `apps/deck/decks/fund-1/README.md` before changing slide source, styles or model inputs.
- The website preserves its deployed live contact behavior. Do not replace it with local preview forms or labels.
- Keep generated deliverables, raw materials, design experiments and dependency caches out of tracked source.
- Validate with `npm test`, `npm run typecheck`, and the affected app build(s).
