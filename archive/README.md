# Historical source

This folder preserves previous application/deck code, including the 20-page
React Fund 1, the earlier fundraising deck and the legacy website. It is excluded
from application compilation, Tailwind scanning and runtime imports. Original
file hashes and checkout state are recorded in `docs/migration`.

Current website and presentation work belongs in `apps/web` and `apps/deck`.
The full pre-migration checkout is also backed up in the external production
workspace by the migration installer. Historical generated PDFs stay there.
